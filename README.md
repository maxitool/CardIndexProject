# CardIndexProject (Медицинская картотека)

**CardIndexProject** — это мобильное приложение для операционной системы Android, предназначенное для автоматизации ведения медицинской картотеки, ведения дневника приёма пациентов, локального структурирования документов и подготовки данных к синхронизации с сервером.

## 🛠 Технологический стек и характеристики проекта
* **Язык программирования:** Kotlin (с поддержкой Gradle Kotlin DSL)
* **Архитектурный шаблон:** MVVM (Model-View-ViewModel) с использованием `Android Architecture Components` (`ViewModel`)
* **Минимальная версия Android (minSdk):** API 27 (Android 8.1 Oreo)
* **Целевая версия Android (targetSdk / compileSdk):** API 34 (Android 14)
* **Сборка проекта:** Gradle (версия 8.6)

### Использованные зависимости
* **AndroidX & Material Components:**
  * `androidx.core:core-ktx` — расширения Kotlin для Android-разработки.
  * `com.google.android.material:material` — компоненты дизайна Material Design (используется `NavigationView` и др.).
  * `pl.droidsonroids.gif:android-gif-drawable:1.2.28` — специализированная библиотека для плавного покадрового управления GIF-анимациями в UI.

## 📂 Структура исходного кода
Проект организован по классической многопакетной структуре внутри Android-модуля `app`:

* 🏛 **`activities`** (`AccountActivity`, `DiaryActivity`, `LoginActivity`, `RegistrationActivity`) — основные экраны приложения, управляющие жизненным циклом и связывающие UI со слоем логики.
* 🧩 **`fragments`** (`DiaryFragment`, `MedicalCardFragment`) — изолированные части интерфейса. `MedicalCardFragment` реализует динамически раскрывающиеся блоки (жалобы, анамнез, объективно, диагноз, лечение) на базе кастомной коллекции.
* 🔄 **`adapters`** (`RecyclerViewDocFragmentsAdapter`, `RecyclerViewDocumentsAdapter`, `SpinnerDocActionsAdapter`) — адаптеры для связывания медицинских данных, списков открытых вкладок документов и выпадающих списков со стандартными UI-компонентами Android.
* ⚡ **`controllers`** (`AnimationController`) — компонент, инкапсулирующий логику покадрового воспроизведения GIF-анимаций в зависимости от бизнес-состояний (например, открытие/закрытие пароля по нажатию на «глаз» или анимация бокового меню).
* 📦 **`viewmodels`** (`LoginViewModel`, `RegistrationViewModel`, `DiaryViewModel`) — хранение и обработка UI-состояний, защищающая данные от уничтожения при повороте экрана устройства.
* ⚙️ **`settings`** (`Settings`, `ColorsSettings`) — конфигурация приложения, динамическая смена тем и цветовых палитр.
* 🎨 **`res/`** — ресурсы приложения, включая селекторы, кастомные формы (`shape_*.xml`), анимации и переводы строк (поддержка мультиязычности).

## ⚙️ Установка и развёртывание

### Требования
* **Android Studio** (рекомендуется версия Ladybug / Meerkat или новее).
* **JDK 17** (или совместимая версия для Gradle 8.6).

### Пошаговый запуск
1. Клонируйте репозиторий с проектом:
   ```bash
   git clone https://github.com/maxitool/CardIndexProject.git
   ```
2. Откройте Android Studio и выберите пункт **File -> Open**, указав на корневую папку репозитория.
3. Дождитесь окончания синхронизации Gradle-проекта (Gradle Sync).
4. Собрать проект можно через верхнее меню **Build -> Make Project**.
5. Запустите приложение на подключенном физическом устройстве или Android Emulator, нажав кнопку **Run (Shift + F10)**.
